# Simple-return heating-oil run of 17 October 2026, kept unchanged

`batch60_heating_oil_test.py`, its printed results and its monthly panel as committed in `012aa19`, with a copy of the unchanged `backwardation_test.py` it imports. The protocol (`../batch60-heating-oil-protocol.md`) defines the held-contract return as a log return, ln(C1(t1)/C2(t)); this run used the simple return C1(t1)/C2(t) − 1 that the imported v2 builder supplies for WTI and gas. An audit in the fourth batch of 17 October 2026 found the mismatch; the corrected script in the parent folder uses the log return for heating oil only (the WTI and gas protocols and outputs are not changed). The premium slope moved from 0.3582 (t 1.67) to 0.3276 (t 1.55) and the out-of-sample R² from −0.92 percent (Clark–West t 0.37) to −0.95 percent (0.31); scarcity is unaffected (it does not use returns). Both runs reject the premium hypothesis. These files reproduce byte for byte when run from a copy of this folder. Do not cite their premium figures as current.
